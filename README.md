## 📌 About The Project

Retail Shop is an SQL-based database project designed to demonstrate fundamental database management concepts. It includes database creation, table creation, sample data insertion, and SQL JOIN operations to retrieve meaningful information from related tables.

## 🚀 Features

- 🗄️ Database and table creation
- 👥 Customer information management
- 📦 Order and product details
- 🔗 Primary key and foreign key relationships
- 🔍 SQL JOIN operations
- 📊 Data retrieval using SQL queries

## 🛠️ Tech Stack

- **MySQL** – Relational database management system
- **SQL** – Database query language
